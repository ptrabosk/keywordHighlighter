Offisght Operations

Rule Highlighter

Highlight inbound messages using opt_out_deterministic_rules.json. Hover a match to see editable rule guidance.

Shortcut activity

When a rule keyword is highlighted, the extension records limited usage information and the number of rendered rule highlights. Activity in text fields is ignored. It does not collect message text, matched text, rule names, or field contents. Uploaded usage events are deleted after 90 days.

Targeting

Runs only on the supported Operations page: https://ui.attentivemobile.com/concierge/*.

Display

Categories

Each action in the rules file can be enabled independently and assigned a color.
